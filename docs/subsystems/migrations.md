# uci-defaults migrations

Scripts in `root/etc/uci-defaults/` run on first boot and again on every package
upgrade, so each one must be idempotent and must not undo a choice the user made
after it first ran. Most "one-shot" scripts therefore set a marker in
`5gmodem.@5gmodem[0]` (or `5gmodem.health`, `5gmodem.sms`) and exit early when it
is present; a marker can be bumped (`ifdedupe_done=2`) to re-run a fixed version.
"Fresh install only" defaults skip when their section already exists. Behaviour
of these scripts must stay exactly as is.

| Script | What it migrates or seeds, and why |
|---|---|
| `29-5gmodem-sms-migrate.sh` | Copies SMS settings from `/etc/config/sms_tool_js` (owned by luci-app-sms-tool-js, which this part grew out of; sharing the file blocked co-installation and apk kept the foreign file, parking ours as `.apk-new`) into `5gmodem.sms`, only keys still empty on our side; the old file is left for the fork. Once (marker `/etc/5gmodem/.modemdir-migrated`) moves non-empty phonebook, USSD and AT lists from `/etc/modem` to `/etc/5gmodem/modem` without overwriting newer files. |
| `30-5gmodem-sms-setup.sh` | Sets exec bits, creates list dirs, ensures `5gmodem.sms`, rewrites a national number prefix (`48`, `7`) to `+7`: without `+` the network treats it as national (MM over QMI: "QMI protocol error (54) WmsCauseCode", PDU path: `+CMS ERROR`). Runs the SMS USB hotplug once so an already connected Compal is configured without a reboot; drops LuCI caches. |
| `31-5gmodem-sms-off.sh` | Enables or disables the SMS LED notifier according to `sms.lednotify`. |
| `32-5gmodem-health-defaults.sh` | Fresh install only: health watchdog and traffic failover on, healing off. Failover defaults on because an uplink with an address but no internet looks healthy to the kernel (a Wi-Fi uplink at top priority held traffic for seven minutes over four working modems). |
| `33-5gmodem-stats-defaults.sh` | Fresh install only: statistics collection on, `persist=0` (series in `/tmp`, no flash wear); `show_stats=1` if unset. |
| `34-5gmodem-healing-default.sh` | Once (`health.healing_migrated`): removes `healing='0'` so the new default (on) applies. The 0 was written by the watchdog dialog, which saves every key on any change, not chosen by the user; a 0 set later is respected. |
| `35-5gmodem-healwifi-default.sh` | Same as 34 for `heal_wifi` (`health.healwifi_migrated`). |
| `36-5gmodem-dedupe-ifaces.sh` | Runs `modemswitch.sh dedupe-ifaces` once (`ifdedupe_done=2`) to remove duplicate interfaces created by IMEI-randomising sticks. Marker bumped from 1 to 2 because the first version removed nothing (its default-route guard matched every duplicate). |
| `37-5gmodem-dedupe-fwzone.sh` | Once (`fwzone_dedupe`): removes repeated network names in every firewall zone; the old `_fw_zone_add` deduplicated only the added network, and `modem` reached 24 entries. Harmless for fw4, but bloats the config and diagnostics. |
| `40-fibocom-ipv6-ra.sh` | Adds firewall rule "Allow modem RA (fe80::1)": all ICMPv6 from `fe80::1` on wan (RA and the gateway's NA). The default `Allow-ICMPv6-Input` was not enough on FM350; idempotent by rule name, harmless without an IPv6 modem. |
| `41-fix-wan-zone-list.sh` | Splits a wan zone list element glued by old versions (`add_list` on `option network 'wan wan6'` made one element "wan wan6", wan left the zone, LAN lost NAT). Only touches the zone if a quoted element is found; reloads the firewall. |
| `42-5gmodem-smscmd-presets.sh` | Once (`sms.cmd_presets`), and only if there are no `smscmd` sections: seeds two disabled examples (`reboot`, and `modem` -> `reboot_modem.sh power`, power-cycle instead of `AT+CFUN=1,1` because it also recovers a hung modem) with a 10 s delay so the reply leaves before the link drops, plus `cmd_secret='secret'` so the field's role is obvious. The section stays off (`cmd_enabled`). |
| `43-5gmodem-extip-migrate.sh` | Moves `speedtest_ip_url`/`speedtest_cc_url` to the shared `extip_url`/`extip_cc_url` (now also used by the modem card and Internet priority) if the new key is empty, and deletes the old keys. |
| `44-5gmodem-r11e-bands.sh` | Once (`r11e_bands_migrated`): deletes `save_band*`/`band_full` in MikroTik R11e-LTE (2cd2:0001) sections. Before 2.4.65 a modem replaced in the same port inherited the old modem's bands, and R11e had no band profile, so any saved set was foreign; the dial proto would now write it (a set without B20 was observed). |
| `45-5gmodem-mm-init-eps.sh` | For `proto=modemmanager` with `iptype=ipv4v6` and no policy, sets `init_epsbearer=default` (otherwise the stock handler clears the initial bearer and IPv6 never comes up). Removes `init_epsbearer=default` from SoC-modem interfaces (`qcom-soc`, `*.remoteproc`, or a `modem_path` with `remoteproc`), where it breaks dialing. No network restart. |
| `46-5gmodem-fcc-unlock.sh` | Links `/etc/ModemManager/fcc-unlock.d/<vid:pid>` to our `fcc-unlock.sh` for DW5821e / T77W968 ids (413c:81d7, 81e0, 81e4, 81e6, 81d8, 0489:e0b5, e0b4) unless a link already exists. MM calls these only when the modem refuses to enable radio and rereads the dir on each attempt. |
| `5gmodem-rebind-allow.sh` | Once (`rebind_seeded`): adds OS connectivity-check domains (msftncsi.com, msftconnecttest.com, connectivitycheck.gstatic.com, captive.apple.com) to dnsmasq `rebind_domain`. Cellular CGNAT/DNS interception returns private addresses for them, rebind protection drops them and clients show "no internet" while working. |
| `5gmodem-ttl-migrate.sh` | Removes the old `/etc/nftables.d/10-5gmodem-ttl.nft` include: its untyped chain before fw4's declarations failed with "Chain of type filter is not supported" on cold boot, leaving no fw4 table and no masquerade. The iface hotplug recreates TTL rules. |
| `fix_bogus_hilink.sh` | Removes `kind=hilink` (and `netdev`, `at_debug`) from non-HiLink vendors. Old `is_hilink()` treated any modem with a netdev as HiLink (qmi_wwan creates wwan0; Telit LM960 1bc7:1040 became unconfigurable), and the stored value is checked first, so a code fix alone never reached upgraded users. Huawei 12d1, 1bbb:0196, ZTE 19d2, 15a9, 1076:8002, 0846:68e1 and sections without vidpid are left alone. |
| `seed_widgets.sh` | Once (`widgets_seeded`): seeds a ping widget (youtube.com, click mode) if none exists, one service widget for the first installed proxy panel (nikki before ssclash, nikki replaces ssclash), and `netpri_rank=icon` explicitly in config so the settings page and the Network page agree. |
| `set_5gmodem_port.sh` | Sets exec bits on the main scripts and HiLink helpers; drops LuCI caches. |
| `setup_mm_filter.sh` | Replaces the dead udev approach (`99-5gmodem-mm-ignore.rules` with `ID_MM_DEVICE_IGNORE`; OpenWrt ships libudev-zero, which never reads rules, and no udevadm) with per-modem `mm_exclude` used by `mm-inhibit.sh`. Deletes the rules file and `mm-filter.sh`; for sections without `mm_exclude` sets 1 for kernel protos and 0 for `modemmanager`, so behaviour does not change silently; runs one inhibit pass. |
| `stamp_modem_ifaces.sh` | Backfills `network.<if>.modem_path` and, separately, `modem_imei` from the modem sections (see ownership stamps in [interfaces.md](interfaces.md)). IMEI is stamped independently because interfaces of older versions already had a path; sections of absent modems are migrated too, since `resolve` only visits present ones. |
