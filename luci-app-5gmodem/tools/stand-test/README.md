# stand-test: live checks on a test router

Checks a router running luci-app-5gmodem over ssh and a headless browser, with no human involved, and writes a PASS/FAIL report. Not packaged (luci.mk installs only `root/` and `htdocs/`).

- Run: `STAND_PASS=<root password> tools/stand-test/run.sh [-H 192.168.11.1] [-o dir]`. The exit code is non-zero if anything FAILs. The report is `<dir>/report.tsv` (`RESULT  name  seconds  detail`); screenshots and the backend calls of every page go to `<dir>/pages/`.
- The host needs `ssh`, `setsid`, `timeout`, `python3`, Chrome/Chromium and Node >= 22 (global `WebSocket`). The password goes to ssh through a temporary `SSH_ASKPASS` script, and the LuCI session is created with `ubus call session login` over ssh, so no password is typed into a browser form.
- Default run (about 12 min):
  - `stand/checks.sh` runs on the router (`sh -s`). It calls the read-only backends: metrics `peek`/`cached`/`json`, listmodems/detect/resolve, bands `json`/`mgmtinfo`, simslot, SMS status/recv/newcount (nothing is deleted), AT `ATI`/`AT+CSQ`, a foreign-port refusal, stats, TTL, netpri list/status/ping, extip, health `getconf`, USSD support/status, eSIM, antenna, USB power, the sessionwatch daemon, the interface and a process snapshot.
  - `judge.py` checks the answers: valid JSON, key fields filled in, time limits, and the doctor's check-only verdict (registration + address, the same rule as `doctorOk()`).
  - `rpc.py` repeats the page calls through `/ubus` (`file exec`, `uci get`, `file list`) and `/cgi-bin/cgi-exec`, the same way LuCI makes them. It runs twice: as root and as a temporary restricted rpcd login `standtest` that has only `luci-base` + `luci-app-5gmodem` (+ theme). The restricted run also checks that commands outside the ACL are refused. The login is removed at the end.
  - `pages.mjs` (via `chrome.sh`) opens every page of the app, plus Status/Overview and Network/Interfaces, at 390 and 1280 px. It FAILs on JS exceptions, console errors, the "browser keeps outdated files" warning, error text, missing key elements, or a mutating backend call made during page load. Such a call is blocked in the browser and never reaches the router. It WARNs on HTTP errors, extra page reloads, leftover spinners and horizontal overflow. On the Network page it also presses "Check and fix": the check must answer "connection is fine" without calling any repair verb.
- Options:
  - `--soak MIN` keeps the Network page open for MIN minutes, as a forgotten tab would. `stand/soak.sh` samples the router every 30 s, and `soakjudge.py` checks the interface for flaps, and the samples for memory drift, zombies, hung `sms_tool`, the process count, rpcd RSS, `/tmp` growth, and healing lines in the log.
  - `--destructive` runs `stand/destructive.sh`: it drops one LTE band that is not in use, verifies the change, restores the original list (and the saved uci value), then does a soft radio restart. After each step the modem must be back online (registered, has an address, and a ping through the modem device answers). Nothing starts unless the modem is online first.
  - `--whitelist open,tcp,dnsonly [--wl-min N]` simulates an operator that lets through only a whitelist. It uses a temporary nft table `inet wltest` on the modem device only (output + forward), so LAN and the other uplinks are not touched. The whitelist is the resolved addresses of ya.ru, yandex.ru, ozon.ru and max.ru, plus DNS. The modes decide what 77.88.8.8 still passes: `open` = everything, `tcp` = TCP only, no ICMP, `dnsonly` = DNS only. Before arming, a detached-rollback self-test must pass. The table then deletes itself after N+5 min even if the host disappears. `wljudge.py` FAILs if the watchdog marks the link down, penalises its route or DNS, restarts the interface or runs any healing step.
  - `--pages detail,readsms`, `--widths 1280`, `--no-pages`, `--no-func`, `--no-limited` narrow the run. `USSDCODE='*100#'` enables a real USSD request; without it USSD send is skipped, and it is skipped anyway when the modem reports no USSD support.
- Safety:
  - `/etc/config/{5gmodem,network,firewall,rpcd}` and `uci show` are copied to `/tmp/stand-test-bak` on the router first.
  - At the end, `uci show` is compared with the copy (`config.unchanged`).
  - The default run never writes to the modem or the config, apart from the temporary rpcd login.
