# /5g playground — НЕ ВХОДИТ В ПАКЕТ

Экспериментальный WYSIWYG-конструктор карточек метрик и лёгкий CGI-эндпоинт,
работающий мимо LuCI (напрямую через uhttpd).

**Почему вне `root/`:** `luci.mk` устанавливает всё из `root/` без разбора.
CGI `www/cgi-bin/5g-api` сейчас ОТКРЫТ read-only (без авторизации) — удобно как
плейграунд на тестовом роутере, но в пакете это была бы неаутентифицированная
выдача метрик (IMEI/IMSI/ICCID/оператор/IP) любому в LAN. Поэтому файлы держим
здесь: в репозитории для разработки, но НЕ в устанавливаемом наборе.

**Деплой на тестовый роутер вручную:**
    scp playground/www/5g/index.html      root@ROUTER:/www/5g/index.html
    scp playground/www/cgi-bin/5g-api      root@ROUTER:/www/cgi-bin/5g-api

**Прежде чем паковать в релиз:** вернуть авторизацию (см. историю файла 5g-api,
там был вход через `ubus call session login`) и перенести обратно в `root/`.
